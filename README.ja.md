## このブログについて

これは私の個人ブログです。技術的な内容からエッセイまで、思いついたことをなんでも書いています（笑）

コードをいじった過程を記録したり、日常のどうでもいいことを書いたり。特にテーマは決まっていません～

## ローカルでの実行方法

```bash
git clone https://github.com/sixtdreanight/myBlog.git
cd myBlog
pnpm i
pnpm dev
```

その後、`http://localhost:4321` にアクセスすると表示されます。
