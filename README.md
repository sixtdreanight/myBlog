## 🚀 本地跑起来

```bash
# 把项目克隆下来
git clone https://github.com/sixtdreanight/myBlog.git
cd myBlog

# 安装依赖
pnpm i

# 启动开发服务器
pnpm dev
```

然后打开 `http://localhost:4321` 就能看到了。
