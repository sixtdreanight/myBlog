架构设计总览

方案 1：纯 CSS 驱动 CRT 特效 + 少量 React 组件

特效分层

CSS 层（自动生效，零 JS 开销）
<body data-cyberpunk="on">
— 扫描线（linear-gradient）
— 移动光带（@keyframes beam）
— RGB 色差（text-shadow）
— 暗角（radial-gradient）
— 微闪（@keyframes flicker）
— Glitch（@keyframes glitch）
→ 一个属性，全部效果同时激活
React 层（按需运行）
CyberpunkToggle — 浮动开关
CyberpunkBoot — 启动画面
TiltCard — 卡片 3D 倾斜
PointerService — 共享指针
GlitchTrigger — 随机故障
→ 仅交互逻辑，渲染交给 CSS
